# CONFLORA — Ateliê da chuva

Publicação estática da plataforma educativa CONFLORA, no contexto do BRaVE 2026.

Código-fonte, documentação e versão original estão disponíveis na seção de entregáveis do site.

## Projeto React + Vite

O código-fonte revisado está em [projeto/](projeto/). A publicação estática existente permanece na raiz.

Para executar:

```sh
cd projeto
npm ci
npm run dev
```

Validação: `npm run build` e `npm run test:static`.
Para testes no navegador, consulte [a auditoria](projeto/docs/AUDITORIA_E_CORRECOES.md).
