No new external assets or copyright claims were invented. Images without verified origin stay labeled as existing conceptual art; actual imagery of plant species uses the pre-existing botanical evidence and attribution. A reproducible asset inventory, including byte counts, dimensions when detectable, provenance and directly authored references, is generated by `node scripts/v21-1-media-audit.mjs`.

## Navigation

Group the seven pre-existing desktop destinations by **planning/discovery** and **supplementary resources**, with visible hierarchy and accurate `aria-current`. All routes remain available and unchanged. Improve clarity and touch targets around editor tool controls without modifying annotation coordinates.

## V21 result presentation

A quick-reading summary precedes detailed regional evidence. Areas retain their original IDs and science; numbering displayed to the user is contiguous and separate from the internal annotation indices. Identical area observations reuse the first area’s scientific photos and bibliography, linked by an anchor, while all individual marks still have an area row and expandable conditions. Distinct notes, fields, species or checks prevent deduplication. The PDF references the same shared evidence, without dropping area-specific conditions.

## Motion, accessibility, performance

- Kinetic gallery scroll skew reduced from ±8° to ±2.4°, while original reduced-motion support is preserved.
- WebGL morph effect intensity 0.55 → 0.18, chromatic aberration 0.35 → 0.075 and drift 0.4 → 0.1; WebGL fallback retained.
- Gallery photo credits are explicit links; keyboard focus and interactive targets receive refinements.
- Test responsive widths: 1440, 1024, 768, 390 and 320. Code build is not substituted for browser testing.
- Do not report Lighthouse/LCP/INP/CLS scores without running the corresponding measurement.

## Evidence and publication

Run model, build, V19/V20/V21 regression and V21.1 Chromium browser tests. Archive before/after screenshots where available. Only then publish `/CONFLORA/previews/conflora-v21-1/`, preserving all existing previews.
