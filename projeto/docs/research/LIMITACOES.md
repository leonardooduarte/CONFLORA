# Limitações e fronteiras de aplicação

- **Ausência de projeto hidráulico:** a CONFLORA não mede precipitação, vazão, infiltração, dimensionamento, extravasamento ou mudança quantitativa do escoamento.
- **Foto local:** fotografias permanecem no navegador; o programa não interpreta a imagem automaticamente, nem obtém dados topográficos dela.
- **Brasil:** estudo de espécies em vasos não representa plantio validado em Itapeva; várias fichas carecem de dados de luz e umidade transferíveis. Resultado inconclusivo é o comportamento correto.
- **Iowa:** indicações documentais regionais são ponto de partida para inspeção local, não validação externa ao contexto.
- **Quatro novas fichas:** fotografias identificadas/licenciadas pendentes; não foram substituídas por imagens de outra planta. Luz e/ou posição permanecem desconhecidas quando os ícones do guia não puderam ser confirmados.
- **Fontes:** revisão brasileira é secundária, estudo Bauru é experimental em vasos, guia ISWEP é orientação regional, Kew é registro taxonômico. Os tipos não são equivalentes.
- **Acesso a arquivos:** acesso direto ao GitHub via checkout local está indisponível neste ambiente. Alterações no repositório foram feitas pela conexão GitHub; build/testes executados pelo GitHub Actions precisam de confirmação externa.
- **Compatibilidade:** dados do usuário armazenados em IndexedDB, sem backend, nem sincronização entre dispositivos. Novos componentes não alteram schema.
- **Teste físico:** emulação de dispositivos não substitui Safari/iOS, Android e ensaios de campo. A seleção documental precisa de revisão por botânico local e a drenagem por profissional habilitado.
