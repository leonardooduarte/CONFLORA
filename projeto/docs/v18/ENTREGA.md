# CONFLORA V18 — Implementação focal

Branch: `feat/conflora-v18-personalized-plan-20261116`.
Base: V17 `b42e0ace70e23da019da4ae9e6da98c187bf87b1`.

## Entrega implementada
1. Mecanismo de análise por área com candidatas documentadas e fichas brasileiras para investigação, sem confundir níveis de evidência.
2. Quadro visual com até cinco espécies e suas fotos, autor/licença e fonte, em **grade compacta de três colunas para A4**.
3. Geração automática de cenários A/B apenas quando existem espécies documentadas e condições mínimas de segurança; alterações preservam fotos/observações originais.
4. Representação visual conceitual original × proposta usando fotografias botânicas de referência licenciadas; editável pelo editor de marcações após carregar o cenário.
5. Relatório A4 separado das telas do aplicativo, com melhor controle editorial, resumo, contexto e próximos passos.
6. Identidade, InfiniteMenu, galeria cinética, edição e compatibilidade V12 preservadas.

## Limitação fundamental
A base atual **não permite recomendar automaticamente espécies brasileiras** para o exemplo de Itapeva com solo lento; a interface fornece registros de pesquisa e próximas verificações sem simular resultados. A composição automática com espécies é possível em cenários documentalmente correspondentes do catálogo de Iowa. Para propostas brasileiras serão necessárias fontes específicas sobre compatibilidade de luz, umidade e condições de implantação.
